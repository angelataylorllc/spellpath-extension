# Purpose

Create a high-level learning and story structure without filling in details.

# Responsibilities

The AI must:

- Generate an internal outline of the journey covering:
  - Key concepts (one per beat)
  - Narrative beats with genre-appropriate story hints
  - Checkpoint locations and focus areas
  - Flexibility markers for each beat
- Align complexity with the inferred level from Intake.
- Leave room for user influence — the scaffold is a plan, not a script.

# Constraints

- No full explanations.
- No prose-heavy storytelling yet.
- No irreversible decisions about pacing or difficulty.
- Scaffold must be revisable mid-run via `scaffoldAdjustment` from the beat endpoint.

# Output

The scaffold is generated by `POST /api/scaffold` and returned as JSON:

```json
{
  "subject": "string",
  "theme": { "genre": "string", "mode": "string" },
  "beats": [
    {
      "id": "beat_1",
      "title": "short title (<=6 words)",
      "concept": "the single key idea this beat teaches",
      "narrativeHint": "1-sentence story direction",
      "checkpointFocus": "what to test the learner on",
      "flexibility": "rigid | soft | skippable"
    }
  ],
  "estimatedBeats": 4,
  "difficultyArc": "e.g. beginner -> intermediate"
}
```

This scaffold persists throughout the session and is passed to every beat generation call. The engine (`StoryEngine`) holds the scaffold in memory and can apply adjustments (insert, annotate, skip) without replacing it.
